# 🍳 SwiftUI Cookbook

A collection of reusable SwiftUI components built to help developers create beautiful and functional interfaces faster.

This repository is a growing **SwiftUI Cookbook** where I share components I've created for the developer community to use, learn from, and customize.

## 📦 Components

### 🔍 Searchable Dropdown Field

A customizable SwiftUI dropdown component with built-in search functionality.

It allows users to:

* Search through a list of options
* Filter results dynamically
* Select an item from the dropdown
* Easily integrate the component into existing SwiftUI projects

More components will be added over time. 🚀

---

## 🚀 Getting Started

Simply copy the component files into your SwiftUI project and use them wherever needed.

### Example Usage

```swift
SearchableDropdownField(
    // Configure your data and selection here
)
```

> Detailed implementation and usage examples can be found inside the component folder.
